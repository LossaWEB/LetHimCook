# LetHimCook

Application de recettes (Node.js + Express + EJS + SQLite).

## 🔧 Prérequis
- Node.js installé (version récente LTS)
- npm (fourni avec Node.js)

## ⚡ Lancement rapide
```bash
npm install          # installe les dépendances (recrée node_modules)
npm run dev          # lance en mode dev (nodemon)
# ou
npm start            # lance en mode production (node)
# Ouvrir: http://localhost:3000
